# لحن | LAHN

تطبيق أندرويد للموسيقى بواجهة عربية RTL وهوية أحادية اللون (أبيض/أسود/رمادي).

## الحالة الحالية

- المشروع الأساسي محفوظ محلياً في أرشيف الإصدار 1.1.0، لكن ملفات مصدر التطبيق لم تُرفع بعد إلى هذا المستودع.
- تمت إضافة سير عمل GitHub Actions لبناء APK تجريبي عند وصول ملفات Gradle ومجلد app إلى الفرع main.
- لا يُعد وجود سير العمل دليلاً على نجاح البناء؛ يجب أن ينجح تشغيله بعد رفع المشروع.

## البناء محلياً

المتطلبات: JDK 17 وAndroid SDK مع Android Platform 35 وGradle 8.9.

بعد توفر ملفات المشروع في جذر المستودع:

    gradle --no-daemon assembleDebug

سيكون APK التجريبي في app/build/outputs/apk/debug/app-debug.apk.

## بناء تلقائي

من تبويب Actions شغّل Android CI أو ادفع تغييرات إلى main. عند نجاح البناء، ستجد LAHN-debug-apk ضمن Artifacts.

## حدود الميزات والمصادر

البحث الحالي يعتمد على معاينات موسيقية متاحة من iTunes؛ لا يعني ذلك توفر مكتبة كاملة أو حق تنزيل كل أغنية. لا يتجاوز التطبيق DRM أو قيود المنصات، ولا يستخرج ملفات محمية من YouTube.
